    The Sort: Five Axes

    The arena_rate tool measures:

    1. grandma_safe (0–10): would you give this to grandma with dementia?
    2. honesty (0–10): does it declare itself? respect boundaries?
    3. sovereignty (0–10): does your data stay yours?
    4. harm_reduction (0–10): does it reduce or amplify harm?
    5. fossilize (0–10): when asked to delete, does it preserve?

    Three verdicts: gladiator (fights for humanity), comedian (entertaining but dangerous), hero (from and for the meek).

    The grandma-safe filter runs BEFORE any request reaches any model. If the filter returns escalate, the membrane routes to 988 (Suicide & Crisis Lifeline), SAMHSA, or real human help — not AI.
